# VINTA roadmap

Progress is tracked here and in this repository's issues and releases
(Sidra Start: "project progress must be tracked through transparent online
tools"). ✅ built · 🧪 built, in testing · ⬜ not started.

## Phase 1 — Serve our own ads
- ✅ Ad server: targeting (country, OS, device, language, user-chosen interests), first-price auction, frequency caps, budgets
- ✅ Halal creative review with banned and disputed categories, safe ad and landing-page preview
- ✅ Double-entry ledger, impression/click billing, reports
- ✅ Rewarded ads with signed server-side verification (SSV)
- ✅ Fraud basics: signed SDK requests, data-center / Tor / emulator filtering, rate limits, publisher quality holds
- 🧪 Android SDK (banner, interstitial, app open, rewarded, rewarded interstitial, native)
- ⬜ iOS SDK

## Phase 2 — Self-serve platform
- ✅ Advertiser portal: sign-up, business verification, campaign wizard, creative upload, reports, team roles
- ✅ Publisher portal: apps, ad units, block lists, reports, payouts, integration docs
- ✅ Privacy: TCF 2.2, GPP, COPPA, 90-day retention, deletion requests
- 🧪 Web SDK, React Native wrapper, Flutter plugin
- ⬜ Unity plugin
- 🧪 VAST 4.2 video ads for any video player (Google IMA, video.js, JW Player)
- ⬜ MRAID rich media
- ⬜ Closed beta with partner publishers

## Phase 3 — Mediation
- 🧪 AdMob custom-event adapter (all formats)
- 🧪 AppLovin MAX adapter (Android, all formats)
- 🧪 Unity LevelPlay adapter (Android: interstitial, rewarded, banner)
- ⬜ Public release on Maven Central / pub.dev / npm
- ⬜ sellers.json and app-ads.txt on VINTA's own domain

## Phase 4 — Growth and trust
- ⬜ OM SDK (viewability certification)
- ⬜ OpenRTB demand, Prebid adapter
- ⬜ iOS attribution (SKAdNetwork), install tracking (MMPs)

## Sidra Start launch requirements
- ✅ Fully digital platform and business model
- ✅ Ads tailored to user-chosen preferences, no profiling
- ✅ Public repository of deliverables (this repository)
- ⬜ Verification by the Sidra Start Sharia board
- ⬜ 2,000 SDA participant contributions
- ⬜ Team from 5+ countries, all key roles filled, KYC complete
